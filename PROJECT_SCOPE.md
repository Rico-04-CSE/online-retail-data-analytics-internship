# Project Scope

## Primary analytical question
How can transaction-level retail analytics improve revenue visibility,
forecasting, decision-making and resource allocation?

## Scope
- Data acquisition
- Data quality
- Descriptive analytics
- EDA and visualization
- Revenue forecasting
- Model evaluation
- Prescriptive scenario optimization
- Analytics delivery

## Out of scope
- Claiming actual company profit or cost savings from the public dataset
- Production deployment to the original retailer
- Real-time customer-level interventions
